# AI Resume Analyzer 🚀

An AI-powered resume analyzer built using Python and Streamlit.

## Features
- Resume PDF Upload
- Skill Detection
- ATS Score Analysis
- Missing Skills Detection
- Resume Suggestions
- Analytics Dashboard

## Technologies Used
- Python
- Streamlit
- PyPDF2
- NLP
- matplotlib

## How to Run

pip install -r requirements.txt

streamlit run app.py
